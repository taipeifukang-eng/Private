## 重查依據

- `app/monthly-status/page.tsx`、`app/monthly-status/edit/[id]/page.tsx`、其獎金／補助／匯入元件，對照 `Monthly.vue`、`MonthlyEdit.vue`。
- `app/admin/performance/page.tsx`、`components/performance/PrescriptionTab.tsx`、`lib/performance/bonus-calc.ts` 及對應 API，對照 Performance 系列 Vue 頁。
- `app/admin/activity-management/page.tsx`、`app/admin/activity-management/schedule/[id]/page.tsx`，對照 Campaigns／CampaignEdit／CampaignSchedule。
- `app/inventory/page.tsx`，對照 `Inventory.vue` 與 workspace inventory API。
- 巡店及任務以原始頁、既有遷移清單和本次工作區的 Vue 頁再次確認，沿用 verification.md 已有的測試證據；不把舊測試算成新增功能已測。

## 後續驗收單位

每一項須以「入口 → 讀取 → 操作／計算 → 寫入或下載 → 回讀／重開」驗收，並核對無權限、空資料、錯誤重試、未儲存草稿與不同門市。全站目前仍是部分完成；以路由數、頁籤數或可編輯欄位數推算完成率沒有意義。
