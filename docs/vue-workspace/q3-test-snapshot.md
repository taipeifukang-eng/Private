- 複製前備份測試區巡店範本／評級／改善回補設定。既有測試範本保留但停用，啟用複製的 27 個範本，避免新增巡店時重複列出題目。評級與回補設定對齊正式區擷取版本。

- 匯入期間僅於交易內暫停相關 USER triggers，保留原紀錄計算值；交易後已恢復，驗證沒有遺留停用的核心 triggers。
