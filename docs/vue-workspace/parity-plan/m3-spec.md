## A. 任務管理與派發（W07、W09、P03）

- **A.1 刪除流程模板（Q1 = block_and_type_name，與舊版不同）：**
  - 權限照舊版：模板建立者或有 task.template.delete 者可刪；管理員可刪全部。
  - 底下只要還有「待處理」或「進行中」的未封存任務，就擋下並提示先完成或封存。
  - 可刪時，確認視窗要求輸入模板標題，完全相符才能刪。
  - 刪除連帶指派、勾選紀錄、協作者，走交易式 RPC（supabase/workspace-dev，附 rollback）。
- **A.2 刪除已完成任務（Q2 = delete_with_audit，與舊版不同）：**
  - 照舊版：只有已完成的任務可刪，需 task.template.delete，永久刪除連帶勾選紀錄與協作者。
  - 新增：刪除時寫一筆稽核紀錄（誰、何時、哪個模板與任務、任務摘要），刪除與寫紀錄在同一交易。
  - 入口照舊版：模板列表選單與模板詳情每筆任務旁。
- **A.3 模板列表（Q3 = show_all_with_badge，與舊版不同）：** 範圍內的模板全部顯示；沒有未封存任務的模板標示「尚未指派」，並可直接按「指派」。剛建立與剛複製的模板立即可見。
- **A.4 已封存任務頁權限（Q4 = role_and_permission_with_backfill）：** 維持新版「身分加 task.view_archived」；上線前提供正式區 SQL，把現有能進舊版封存頁的主管角色補授權 task.view_archived（含預覽與 rollback）。導覽入口依 approvals nav-archived-feature-gate 改回舊版。
- **A.5 封存任務詳情（Q5 = readonly，與舊版不同）：** 唯讀，不能再勾選；要再做用「複製任務」。
- **A.6 建立任務的部門限制（Q6 = strict_with_override，與舊版不同）：** 預設被指派人必須屬於所選部門；可明確勾選「跨部門支援人員」加入其他部門的人，畫面與資料上都標示為跨部門支援。上限（50 區段、1000 項目）維持新版。
- **A.7 不另問、直接做：**
  - 模板詳情顯示範圍內全部未封存任務（舊版只顯示本人參與，屬 bug，D07）。
  - 派發不選人就指派給自己、派發取代原協作者、封存需 task.template.delete、封存整批原子、複製封存任務、模板編輯鎖定、建立與編輯需管理權限（D08）：照舊版或既有新版做法。
  - P03：補新舊建立結果的寫入對等測試，以及 TaskStepFields、TaskSchedule 的回歸。

## B. 任務執行、我的任務、儀表板（W08、W10）

- **B.1 管理者打開別人的任務（Q7 = edit_with_log，使用者選擇非建議項）：**
  - 有任務管理權限的角色（含系統管理員）可以打開非自己參與的任務，並可代為勾選與填備註。
  - 每次代為勾選、取消、改備註，都記錄代做者（誰、何時），在任務詳情的步驟紀錄顯示「由 OOO 代為勾選」。
  - 上線前比對舊版 admin/manager 名單與新版有任務管理權限者，有出入列給使用者。
- **B.2 我的任務去重（Q8 = dedupe_keep_progress，與舊版不同）：** 去重鍵照舊（同範本、同部門、同區段）。有任何進度的那筆一律顯示；只有完全沒動過的重複卡片才收起來。若多筆都有進度，全部顯示並標派發日期。
- **B.3 已完成的判定（Q9 = all_sections，與舊版不同）：** 所有區段所有步驟完成才是「已完成」，取消勾選退回「進行中」；列表另顯示「我的進度 x / y」（只算自己區段）。
- **B.4 儀表板（Q10 = progress_everywhere，與舊版不同）：** 統計卡、表格徽章、進度條一律以勾選紀錄推算的整體完成為準，與 B.3 同一套算法。
- **B.5 不另問、直接做：**
  - 區段被改掉或刪除：擋下並提示聯絡派發人，列表標「區段已變更」。
  - 儀表板範圍照舊版（只列我參與的任務、統計卡限有管理門市者、其他人顯示本月人員狀態捷徑）；加頁面權限檢查；2 秒輪詢改為手動重新整理加 60 秒背景更新。
  - 新增 Dashboard.vue，導覽「儀表板」不再連回舊站。
