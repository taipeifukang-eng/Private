# M6 第三批 3a：各頁可見角色清單（Z3）與驗收備註

範圍：W30 診所自費藥毛利、W31 診所截圖與 PDF。頁面路徑 `/store/clinic-selfpay-margin`，工作台導覽「診所自費藥毛利計算」。權限採正式區 `has_permission` 語意（不檢查 `roles.is_active`、無資料庫端管理員繞過，只有 `profiles.role==='admin'` 應用層後備）。規則抽成共用純函式 `lib/clinic-selfpay/access.ts`（`resolveAccess`），與舊版 `app/api/clinic-selfpay/_lib.ts` 逐字相同。本清單沒有連正式區，請老闆確認各角色可見範圍是否符合預期。

## D1：選單可見 = 實際能用（看得到就一定能用）

導覽入口出現的條件：「能用計算器」或「能管理主檔」。舊版導覽用的四個月報權限碼（`monthly.status.view_own`、`monthly.status.view_all`、`employee.movement.manage`、`store.manage`）單獨持有時，舊版看得到選單但 API 回 403，新版不再顯示。

| 身分 | 條件 | 導覽入口 | 計算器（匯入診所檔、截圖、看批次、匯出 PDF） | 價格主檔與歷史、匯入價格、關帳 | 刪除批次 |
|---|---|---|---|---|---|
| 系統管理員（profiles.role 為 admin）且職稱不是門市型 | 應用層後備 | 有 | 有 | 有 | 有 |
| 管理型職稱：經理、副理、區經理、營業經理、區域經理、門市經理（職稱包含） | 職稱規則 | 有 | 有 | 有 | 有 |
| 門市型職稱：店長、代理店長、督導、督導(代理店長) | 職稱規則 | 有 | 有（限自己綁定的門市） | 無（403） | 無（403） |

| 沒有任何相關權限與職稱 | 無 | 無 | 401／403 | 403 | 403 |

## 門市範圍

- 非 admin：只看自己在 `store_managers` 綁定的門市；區經理若沒綁門市，看到 0 間門市。
- admin 且職稱不是門市型：看全部啟用門市；admin 但職稱是門市型，仍只看綁定門市（沿用舊版）。
- 別店店長讀取批次或明細一律 403，清單也看不到。

## 驗收備註

- 沒有真實診所價格檔與診所檔樣本（Z4 仍待提供）；全部用自造測試檔（`tests/fixtures/clinic-selfpay/`，假診所、假健保碼、VW／ZT 測試門市、2038 年）。真實樣本比對測試已就緒，樣本放進 `盤點測試檔/` 後自動執行，沒有樣本會乾淨略過。
- 價格是匯入當下的快照，之後改價、再匯入或關帳都不會改寫舊批次。
- PDF 絕不含成本與毛利（版面函式只收健保代碼、藥名、數量、藥費、藥費總額）。
- 截圖桶 `clinic-selfpay-screenshots` 為私有桶，只用 60 分鐘簽名網址讀取；刪批次先刪儲存物件，刪檔失敗回 502 並保留資料列。
- 正式區上線前要先套用 `m6-sql/` 的截圖桶草稿（見該資料夾 README）。
