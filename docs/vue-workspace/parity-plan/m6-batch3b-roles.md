## 3b 驗收備註

- 沒有真實督導日誌與真實錄音樣本；OpenAI 一律使用測試用假回應或本機規則，沒有呼叫真實 OpenAI。
- 每月 OpenAI 上限 US$30（2026-11-22 問卷決定）：估算達 80% 與 100% 只通知系統管理員（首頁提醒），100% 自動停用 AI、退回手動文字稿與本機規則，每月 1 日（台北時間）歸零。
- 寫入受舊版資料表觸發器與 RLS 限制：角色被停用的帳號在新版可讀、不能寫（回 403 附說明）。
- 新增追蹤需要 follow_up 權限（管理者若只有 manage 不能新增追蹤），待老闆確認是否放寬（需改正式區政策）。
- 正式區上線前要先建立 `m6-sql/` 的 W32 軟刪除函式與 W33 的五張表、兩個函式。
