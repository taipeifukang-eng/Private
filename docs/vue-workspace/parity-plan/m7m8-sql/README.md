### 套用順序與注意

1. 先執行 `00-readiness-check.sql` 與 `11-g01-preview-before-apply.sql`（都是唯讀）。
2. 沒有 MISSING 後，執行 `10-g01-catalog-rules.sql`，核對函式清單，COMMIT。
3. 新版第 1 批不需要補 `maintenance-photos`（工單照片）、QR 觸發器（第 2 批）。
4. 附件新規則（照片縮小、4MB 上限、刪除只標記）全在應用程式，不需要改正式區儲存空間設定（儲存空間單檔上限仍是 20MB，比 4MB 寬，沒有衝突）。
